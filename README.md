# 🎵 AI Music Composer with Emotion & Scene Understanding

An AI-powered music composition project that generates mood-based soundtracks from images. The application analyzes the visual content and creates music that matches the detected atmosphere and mood.

## ✨ Features

* 🖼️ Upload JPG/PNG images
* 😊 Image-based mood and emotion analysis
* 🎬 Scene and visual context understanding
* 🎵 AI-generated original soundtrack
* 🎚️ Custom mood, tempo, and duration
* ▶️ Play generated music directly in the app
* 💾 Download the generated WAV file
* 💻 Interactive Streamlit interface

## 🛠️ Technologies Used

**Python | Streamlit | MusicGen | Transformers | CLIP | MediaPipe | Generative AI | Computer Vision**

## ⚙️ How It Works

```text
Image
  ↓
Emotion & Scene Analysis
  ↓
Mood Detection
  ↓
Music Prompt Generation
  ↓
AI Music Generation
  ↓
🎵 Generated Soundtrack
```

## 🚀 Run the Project

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

The application will open in your web browser.

## 🎯 Project Goal

This project explores the combination of **Computer Vision and Generative AI** to create personalized music based on visual content and emotional context.
